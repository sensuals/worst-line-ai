Entry for make.fun's The Worst Line an AI Could Say bounty: one pickup line, 140 characters or fewer, the worst an AI could say. The program writes the line to entry.txt: "I have been assigned to love you. My supervisor has been notified."

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
